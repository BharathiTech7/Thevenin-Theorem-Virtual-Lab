# ⚡ Virtual Electrical Engineering Laboratory

An interactive web-based **Virtual Lab for performing Thevenin's Theorem experiments**, developed as part of the **Virtual Labs Project, Department of Electrical Engineering, IIT Roorkee**.

The application recreates a laboratory experiment in the browser, allowing students to connect circuit components, use virtual measuring instruments, take readings, perform calculations, and verify experimental results.

## 🚀 Features

- 🔌 Interactive circuit connections using virtual wires
- ⚡ Virtual Power Supply with voltage control
- 📏 Virtual Ammeter, Voltmeter, and Digital Multimeter
- ✅ Real-time circuit connection validation
- 💡 Terminal highlighting for guided connections
- 🤖 AI Guide with step-by-step instructions and audio narration
- 🧮 Experimental readings and Thevenin's Theorem calculations
- 🖨️ Experiment report generation

## 🧪 Experiment Workflow

The experiment is divided into three stages:

1. **RTH Measurement** — Measure the Thevenin resistance using the Digital Multimeter.
2. **VTH Measurement** — Measure the Thevenin voltage using the Voltmeter.
3. **IL Measurement** — Measure the load current using the Ammeter.

The measured values are then used to verify **Thevenin's Theorem**.

## 🎮 How to Use

1. Start the experiment and set the required component values.
2. Follow the instructions provided by the AI Guide.
3. Connect the required circuit terminals using virtual wires.
4. Verify the circuit connections.
5. Take and add the required readings.
6. Perform the calculations and verify the result.
7. Generate the experiment report.
